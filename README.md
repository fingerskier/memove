# memove
MeMove is a movement tracker

* Browser / PWA
* Tracks device movement: GPS and/or IMU
* Determine, by speed, whether walking, running or driving
* Keep a log of _bouts_ showing distance and time traveled
* Allow marking of _bouts_ as general, exercise, work, etc.
* Generate reports;  e.g. work bouts in a certain date-range
* Background tracking?
